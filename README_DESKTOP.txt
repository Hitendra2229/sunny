HOW TO RUN YOUR WEBSITE ANYTIME:
--------------------------------
1. To START:
   Double-click "1_START_WEBSITE_AND_TUNNEL.bat".
   This will:
   - Start the local ASP.NET Core server (http://localhost:5000)
   - Connect the Cloudflare Tunnel
   - Instantly make your website live worldwide on https://www.nvnindia.com

2. To STOP:
   Double-click "2_STOP_PORTAL.bat".

FOLDER CONTENTS:
----------------
- wwwroot/          : All frontend files (index.html, styles, images, JavaScript)
- bin/              : Compiled ASP.NET Core production executable (NVNIndiaServer.exe)
- tools/            : Cloudflare Tunnel utility (cloudflared.exe)
- nvn_india.db      : SQLite Relational Database (courses, applications, inquiries)
- Program.cs        : Backend C# source code
- Data/ & Models/   : Backend database models and services
- server.py         : Python alternative server (if Python is preferred)
